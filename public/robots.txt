# THIS SITE IS DELIBERATELY NOT IN SEARCH RESULTS RIGHT NOW.
#
# skyliftllc.com and skyliftgroup.com serve the same 51 pages. Only the brand
# name, the contact details and the design differ. Two domains with the same
# content means Google picks one and filters the other, and the domain with the
# history wins — so letting both compete would put skyliftgroup.com's rankings
# up against a copy of itself.
#
# The way this site is kept out is the <meta name="robots" content="noindex">
# on every page, NOT a blanket Disallow here. That distinction matters: a
# crawler has to be allowed to fetch a page before it can read the noindex on
# it. Blocking Googlebot in robots.txt instead would leave these URLs eligible
# to appear as bare links with no title and no description, which is worse than
# either outcome we are choosing between.
#
# So: Googlebot and Bingbot are allowed in, and told not to index.
#
# To reverse all of this: set SITE_INDEXABLE = true in src/lib/seo-config.js,
# delete the "while this site is a duplicate" block below, put the Sitemap line
# back, rebuild and deploy.
# ---------------------------------------------------------------------------

User-agent: *
